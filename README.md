# Célula de Engenharia de Software

Repositório da célula: documentação, desafios e entregas dos alunos.

## Estrutura

- `docs/` — documentação da célula (AGENTS, API_CONTRACT, WIREFRAMES, prompts, etc.)
- `desafios/` — um diretório por desafio (`desafio - 0X`)
- `kits/` — kits e materiais de apoio
- `entregas-aluno.md` — tabela de entregas dos alunos (aluno, desafio, link)
